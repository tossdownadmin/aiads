# Operations workflow release

Continue beyond the monitoring home. The next complete operating loop is: inspect dated campaign evidence, review the exact affected entity, prepare a change, retain the source finding in its review and receipt, then return for a later evidence check. No live advertising changes during implementation or verification.

## Implementation

1. Campaign workspace: assigned accounts first, seven/30-day source evidence and campaign-specific outcome/cost beside current configuration; visible source age, dates, metric identity and unsupported outcomes. Show a review queue and navigate to exact campaign/ad. Do not silently blend account spend or create numeric budget suggestions.
2. Reviewed changes: optionally attach a validated immutable monitoring finding to a draft and history, bind it to the digest and verify target/account identity. Stale source evidence must be refreshed before preparing a linked review. Changes remain manual and operator-approved.
3. Audits/reports: preserve source/claim checks, separate optional commercial strategy setup from measurement coverage, link the assigned account and exact entity through workflows, and remove profile setup as a routine monitoring prerequisite. Keep monthly allocation conditional on actual commercial inputs.
4. Skill registry: inspect approved method instructions, identity, version and supported workflow; make built-in monitoring rules/thresholds visible without approving external imports.
5. Accuracy: correct all discovered locale-based Meta currency conversions, preserve currency subdivisions, report missing source states, and run regression/build/UI/live source checks.

## Boundaries

No automatic budget edits, pauses or launches; no CRM/POS profit claims; no guessed qualified leads; no invented targets, forecasts or performance scores. Existing approved campaign access remains unchanged. Competitor ads remain creative references rather than proof of results.

## Live audit follow-up

The first live specialist audit correctly rejected profit, saturation and unbound numerical claims, but its only surviving action asked for optional budgets/targets. The follow-up keeps those strict validators and adds compiled source observations as a separate, labeled output. It suppresses action items whose sole purpose is optional commercial setup while preserving genuine missing-source/outcome warnings. Source observations show exact existing evidence values and matching result costs; qualified cost comparisons use at least ten named outcomes in both periods. Rejected model commentary remains visibly limited and is never replaced with invented AI prose. The focused editor also waits for the selected finding's evidence before allowing a linked review.

Historical report notice: when the saved report’s method/version differs from the selected approved daily method, the page explicitly requests regeneration for current checks and corrected Meta budget formatting. Existing HTML is preserved as a historical snapshot; its formatted configuration values are not silently rewritten.

Final validation after the live-audit follow-up: 289 tests across 43 files and the production build passed. Independent verification also matched 280 supplied live budget/bid values and 74 entity-specific finding-to-change evidence packages. No live advertising changes were applied.
